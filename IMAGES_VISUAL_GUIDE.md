## Design System Elements for Images

### Typography in Images
- **Headlines:** 20px, weight 600, color #242424
- **Body text:** 14px, weight 400, color #242424
- **Labels:** 12px, weight 400, color #6b7280
- **Metrics:** 18px, weight 600, color #101010

### Border & Spacing
- **Card radius:** 12px
- **Input radius:** 8px
- **Padding:** 16px, 24px, 32px
- **Gaps:** 8px, 12px, 16px
- **Border color:** #e5e7eb (silver)

### Shadows
```
Subtle: rgba(36, 36, 36, 0.05) 0px 4px 8px 0px
Medium: rgba(36, 36, 36, 0.1) 0px 8px 16px 0px
```

## File Delivery Checklist

Before providing images, ensure:

- [ ] All 5 images created and optimized
- [ ] Files named exactly as specified
- [ ] Placed in `/public/images/` directory
- [ ] File sizes under 500KB each
- [ ] Aspect ratios correct (4:3 or 1:1)
- [ ] Cal.com color palette used throughout
- [ ] Minimum resolution met (800px width for landscape)
- [ ] Rounded corners and shadows applied
- [ ] Text is crisp and readable
- [ ] Mock data consistent across images

## Integration Steps After Images Ready

1. Place images in `/public/images/`
2. Update landing page component with Image imports
3. Test responsive display on mobile/tablet/desktop
4. Verify image loading and performance
5. Optimize with Next.js Image component

## Example Integration Code

```tsx
import Image from "next/image"

// Hero Section
<Image
  src="/images/dashboard-hero.png"
  alt="LogFlow Dashboard - Real-time tracking and shipment management"
  width={1200}
  height={900}
  className="rounded-2xl shadow-lg"
  priority
/>

// Feature Cards
{mainFeatures.map((feature, i) => (
  <div key={i} className="rounded-3xl bg-white p-8">
    <Image
      src={`/images/${featureImages[i]}`}
      alt={feature.title}
      width={800}
      height={600}
      className="rounded-2xl mb-4 w-full h-auto"
    />
    <h3 className="text-xl font-semibold">{feature.title}</h3>
    <p className="text-slate">{feature.description}</p>
  </div>
))}
```
